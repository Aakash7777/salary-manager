# Design prompt

Used to generate the UI designs in a design tool before building. Kept here because prompts are part of how the solution evolved.

> Design a clean, desktop-first web app UI called "ACME Salary Manager" for an HR Manager at a 10,000-employee company across multiple countries. Mantine components, light theme, indigo accent. Money always shows its currency code; never mix currencies in a total unless labelled "≈ USD". Screens: Employees directory (filters, sortable table, server pagination, Export CSV, Add employee), Employee detail (current salary, salary history timeline, edit/remove), Add/Edit employee drawer (currency read-only, set by country), Change salary modal (live % preview, effective date, required reason), Insights overview (stat cards, pay by country in local currency), Country drill-down (pay by job title with min–max range bars, outliers >25% from role median). Include loading, empty, validation-error and delete-confirm states. 1440px desktop.
